VERSION HISTORY

This is where you can see all the changes done in each version of the mod.
Changes for each unfinished build will not be listed.

Version 2.x

Ver. 2.1
  • Added a new background, "Purgatory".
  • Added a new front asset to "Paradise".
  • Added a new song in Week 3, "Who I Was" with its respective dialogue, cutscene BGM, and cliffhanger cutscene.
  • Added a scared GF asset for "It's Destroyed" and "Who I Was".
  • Added an option in the menu to toggle between two different menu backgrounds.
  • Added two new characters, "Enzo" and "JPG".
  • Added two new freeplay songs, "Casino Park" and "You Can't Run".
  • A few bug fixes.
  • Many minor alterations to the source code that affects UI.
  • Moved to source code and Psych Engine 1.0.1.
  • New intro text.
  • Replaced the outside assets in "It's Destroyed".
  • Re-wrote all dialogue during cutscenes.
  • Updated credits.
  • Weeks 2 & 3 are locked until their previous respective week is cleared (Week 2 unlocks after 1. Week 3 unlocks after 2).
Ver. 2.03
  • Added distressed BF and GF assets for Week 3.
  • Added "Hard" difficulty and re-added "Normal" difficulty.
  • Added seven new cutscene music.
  • Added three new stage backgrounds.
  • Added two new credits.
  • Added two new weeks, three songs each.
  • Moved to Psych Engine 1.0.
  • New intro text.
  • New sad, angry, and corroded Windo spritesheets for "Somberness", "Ständchen", and Week 3 respectively. This also includes their respective health icons.

  • Tweaked the note assets.
  • Updated menu toggle sound.
